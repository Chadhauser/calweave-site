Turn a Google Sheets™ rota into Google Calendar™ shifts

Rotas get planned in spreadsheets — rows and columns are perfect for shifts. But people live out of their calendars. The missing piece is publishing the finished rota to Google Calendar™ without retyping every shift.

The workflow

  1. Build the rota in a sheet: one shift per row — title ("Front desk — Sam"), start, end, location.
  2. Mark each new row NEW in a status column.
  3. Sync: every row becomes a calendar event, and each row stores its event ID.

Changes and cancellations

Because rows are matched to events by ID, editing a shift and re-syncing updates the same event — staff see the change, not a duplicate. Cancelled shifts are marked DELETE and removed on the next sync.

Guard rails worth having

  • Preview before write — check what a sync will create, change or remove before it touches the calendar.
  • A delete safety cap — so a cleared sheet can never mass-delete a live calendar of shifts.
  • Writes off by default on schedules — unattended calendar edits should be something you opt into.

Why not the built-in import?

Google Calendar™ can import a CSV once, but it can only create — never update or cancel — and repeat imports duplicate everything. For a rota that changes weekly, you need a true sync, not an import.
